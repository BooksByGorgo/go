## description

```
You already know how to program --- you just do it in Java. Gorgo Go for Java Programmers takes working Java developers straight to productive Go: every new concept is compared to the Java you already know, and the parts that work the same are mentioned once and skipped.

Twenty chapters run from hello world through types, strings, control flow, functions, methods and embedding, maps and slices, interfaces, and error handling, then into the territory Go is famous for: goroutines, channels, synchronization, context, packages and modules, the essential standard library, JSON and HTTP, gRPC, database access, generics, and testing. Coverage is current through Go 1.26.

Every chapter ends with a complete Try It program, a Key Points recap, and exercises that make you predict output, hunt bugs, and write real code. Three appendices collect the Go proverbs, the tooling ecosystem, and the 70 code review rules used throughout the book.

In the author's own words, "this is a mediocre Go book to get a Java programmer to the level of a mediocre Go programmer quickly."

This is an open source book. You can see the full book at https://gorgo.dev/go. Found something to improve? Please open an issue on our GitHub project.
```
